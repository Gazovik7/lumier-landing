# Lumiér — лендинг «украшение домов гирляндами под ключ»

Второй лендинг для клиента (вешаем-гирлянды.рф) на чистом **HTML + CSS + JS**, без сборки и зависимостей (кроме Google Fonts). Бренд **Lumiér**, стиль — тёмно-изумрудный «новогодний люкс».

## Структура
```
index.html          ← вся страница (разметка + SEO/JSON-LD/OG)
css/styles.css       ← дизайн-система и адаптив
js/main.js           ← квиз-калькулятор, до/после, модалки, карусель, маска телефона
assets/              ← сюда положить картинки из IMAGES.md (создайте папку)
assets/projects/     ← реальные фото объектов из ТЗ клиента (5 проектов, 23 кадра)
IMAGES.md            ← промпты изображений + куда что вставить
ЦА-и-аудит.md        ← портреты ЦА, прогон, дизайн-ревью, антиИИ-проверка
```

## Как открыть
Просто открыть `index.html` в браузере. Для корректной работы шрифтов/иконок лучше через локальный сервер:
```bash
# из папки проекта
python -m http.server 8080
# затем http://localhost:8080
```

## Что сделать перед публикацией
1. **Заявки.** Заполнить `LEAD_CONFIG` в начале `js/main.js` — см. раздел «Настройка заявок» ниже. **Без этого заявки никуда не уходят**, а только пишутся в консоль браузера.
2. **Картинки.** Фото проектов уже лежат в `assets/projects/`. Остальные — сгенерировать по `IMAGES.md` и положить в `assets/` с теми же именами. Пока файла нет, секция показывает изумрудный плейсхолдер со свечением — вёрстка не ломается.
3. **Видео.** Заменить демо-ID `dQw4w9WgXcQ` на реальные ID роликов YouTube в `index.html`.
4. **Реквизиты.** В футере стоит заглушка «ИП/ООО · реквизиты по запросу».
5. **Акция.** Проверить дату «−30% до 10 декабря».
6. **Домен.** Для `veshaem-girlyandi.ru` положить в корень файл `CNAME` с одной строкой `veshaem-girlyandi.ru`, в reg.ru прописать A-записи GitHub Pages (`185.199.108–111.153`) и `CNAME www → gazovik7.github.io`, затем включить «Enforce HTTPS» в настройках Pages.

## Настройка заявок

Сайт статический (GitHub Pages), бэкенда нет. Заявка уходит **параллельно во все каналы**, у которых заполнены поля в `LEAD_CONFIG` (начало `js/main.js`); незаполненные пропускаются. Форма работает в любом случае — пользователь всегда видит подтверждение.

| Канал | Что заполнить | Куда идёт |
|---|---|---|
| `email.endpoint` | `https://formsubmit.co/ajax/girlandahous@yandex.ru` | письмо на почту |
| `telegram.token` + `telegram.chatId` | токен от [@BotFather](https://t.me/BotFather) и id чата | сообщение в отдельный чат бота |
| `webhook` | URL своего обработчика | JSON `{source, name, phone, …, page, ts}` |

Шаги:
1. **Почта.** Вписать endpoint FormSubmit (регистрация не нужна). Первую заявку сервис попросит подтвердить письмом на `girlandahous@yandex.ru` — подтвердить один раз.
2. **Telegram.** Создать бота у @BotFather, создать отдельный чат/группу под заявки, добавить туда бота, узнать `chat_id` через @userinfobot, вписать оба значения.

> ⚠️ **Про токен бота.** На статическом сайте он виден в исходниках страницы — посторонний может слать сообщения в этот чат. Поэтому заводите **отдельного бота только под заявки** и не используйте его больше нигде. Если это неприемлемо — оставьте `telegram` пустым и укажите `webhook` на свой прокси (Cloudflare Worker / n8n / Make), который спрячет токен на сервере.

В Telegram уходит готовое сообщение с подписями полей (форма, имя, телефон, ответы квиза, посчитанная вилка цены, страница).

## Интерактив
- Квиз-калькулятор (5 шагов, моментальная вилка цены, автопереход по выбору).
- Пара «Днём / Вечером» в блоке кейсов — реальные кадры одного дома (КП Глаголево Парк), открываются в лайтбоксе.
- Галереи проектов: миниатюры в карточке + полноэкранный просмотр со стрелками, счётчиком и клавишами ←/→.
- Модалка заказа звонка, лайтбокс портфолио, карусель отзывов, ленивые видео.
- Маска телефона и валидация форм, sticky-хедер, мобильное меню, нижняя панель CTA.

Чистый код, адаптив 360/768/1024/1280, доступность (aria, контраст), `prefers-reduced-motion`.
